### 2. 无动态 Skill 上传接口

设计文档 `docs/enhancements/037-feature-skills-dynamic-upload.md` 规划了：

| 方法 | 说明 | 状态 |
|------|------|:----:|
| `agent.upload_skills` | Base64 zip → 解压到 `skills/` | ❌ 未实现 |
| `agent.list_skills` | 列出已上传 skills | ❌ 未实现 |
| `agent.remove_skill` | 删除指定 skill | ❌ 未实现 |

## 影响

- "内置 workflow"名不副实，需要用户自行实现
- 无法动态上传/更新 agent 的 skill 包
- 每次更新 skill 都需重启 daemon 或手动覆盖文件

## 建议方向

**上传接口**：按 `037-feature-skills-dynamic-upload.md` 实现：
1. 引入 miniz 库用于 zip 解压
2. 实现 `agent.upload_skills` handler（Base64 解码 → 解压 → 写入 `skills/`）
3. 实现 `agent.list_skills` / `agent.remove_skill`
4. 单元测试 + E2E 测试
