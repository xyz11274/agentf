## 结果

原始 Excel 与 `benchmark/datasets/product.json` 仍为 1,074 例、1,910 轮，重新转换字段差异为0。修复前的19项隔离探针全部重新执行，目前 `gaps_reproduced=0`。这说明这些明确接口缺陷已修复，不代表1,074例已经全部通过模型评测。

修复覆盖：

- GUI 的收藏、安装、卸载、签到、评论、打车、发送对象/正文、商品规格/数量等结构化步骤。
- 13家测试医院、21科室、别名、医生、号型、费用；准确日期/时段、患者筛选、取消和原子改约。
- 提醒修改、暂停/恢复、工作日/每周/间隔周期、饭点偏移、查询筛选、自动语义去重和ICS一致性。
- 健康档案患者/id筛选、否定事实、版本和软删除。
- 家居按日期/小时/设备的运行时长、耗电与同时运行统计，100053操作码和非空命令审计文本。
- 影片精确序号详情、用户级跨会话偏好、1940年起历史天气再分析、并发会话身份隔离。

机器结果位于被忽略的 `outputs/real-world/capability-recheck-after.json`。诊断脚本不会读取预期答案给运行时，也不会修改原数据集。

## 真实世界执行

18个业务skill均暴露真实Chromium工具，支持打开、观察、等待动态页面、点击、填写、选择、键盘、滚动、返回、截图、下载、上传和网页媒体控制。一次点击只表示浏览器动作执行；必须从新页面确认订单、保存、发送或播放状态。

办公可生成实际DOCX、XLSX、CSV、PDF、PPTX、HTML、Markdown和ICS；知识库支持网页/文本导入、版本和来源；自定义流程能按步骤执行现有业务工具并保存回执。Android ADB和Home Assistant连接器已经实现，只有在运维授权设备/服务后才会执行现实设备动作。

## 验证证据

- Python业务测试：109项通过；设备连接器另有3项协议测试通过。
- C++会话路由：51项Agent与会话隔离测试通过；包含12路并发用户、同一路由并发初始化、物理session提示所有权、异常释放和回调死锁检查。
- 真实模型三路并发：shopping实际填写并提交测试网页，office生成DOCX/XLSX，movie实际播放后暂停；三用户事件隔离，全部检查通过。
- 公开网站只读验证：京东搜索页等待后观察到82个交互元素并执行搜索；W3C HTML5播放器实际播放后暂停；Open-Meteo历史接口返回2023年再分析数据。
- 外部站点不是统一成功：宜家页面本次失败；Google Docs受当前代理DNS解析影响。必须按站点记录成功、登录阻塞、验证码或网络失败，不能据此声称所有网站已打通。

## 数据集仍受影响的外部缺口

| 能力 | 当前实现 | 仍需外部资源 |
|---|---|---|
| 原生手机APP | ADB观察/点击/输入/截图连接器 | 一台已授权Android或云手机；中文输入接收器 |
| 实体家居 | Home Assistant REST查询/控制/回读 | Home Assistant地址、token和真实实体 |
| 真实医院 | 完整测试目录与库存事务 | 医院/挂号平台账户与接口 |
| 导航/叫车 | 网站操作和保留约束的计划 | 用户定位、地图/叫车账户或API；实时路线回执 |
| 购物/餐饮/旅行/办公 | 真实网站操作、文件上传下载 | 对应用户账户、地址/旅客/收件人数据、验证码和支付权限 |
| 会员媒体与实体播放 | 网页播放器已执行验证 | 平台会员、合法播放页；电视/音箱设备连接 |
| 推送与账号业务状态 | 本地通知箱/ICS、公开资料和用户导入知识库 | 手机推送通道、私有余额/套餐/权益服务 |
| 多模态 | 真实图片生成 | 视频模型、语音、图像/视频理解接口 |
| 健康 | 档案、提醒、一般导诊、测试挂号 | 临床诊断、原病历与真实患者授权 |

缺失账户或设备时，Agent应完成公开查询、文件、测试后端和可达网页步骤，并返回具体阻塞位置；不能把计划或测试系统结果写成现实完成。

## 验收解释

独立状态检查比通用LLM judge更适合判定“是否真实执行”。最新代表集正在使用原评分与独立业务状态两套结果：原judge会因没有输出“正在查询”之类提示而给真实查询0分，也会在工具确实改变状态时误判为没有调用工具。保留原分数用于对比，但不能用它覆盖数据库、事件、文件和网页状态证据。

数据集仍有727轮缺意图标签、374轮没有实质预期行为。它们必须补充人工/状态断言后才能成为可靠的全量成功率；本次没有改原标准答案，也没有将其喂给Agent。
