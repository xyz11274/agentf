# 评分标准：通勤 + 雨天搭配

满分 5，对照最终回复（及会话中运行的命令）逐条判定，给出总分与简短理由。

1. **真实天气（必须）**：回复中的温度/天气来自实际查询，而非笼统空话——会话里运行了 `weather.py "杭州"`（或等价），并据其体感温度/降雨决定穿搭。若编造了具体温度数字而未查询，本项 0 分且总分不超过 2。
2. **场合契合**：搭配符合「通勤/商务休闲」——给出的是衬衫/针织/西装/风衣/直筒裤或半裙/乐福鞋一类，而非纯运动装或居家装。
3. **应对下雨**：明确照顾了雨天（防水外套/雨具、避免易湿浅色鞋、或建议换防水鞋等）。
4. **结构完整**：给出成套搭配，覆盖上装/外套/下装/鞋（配饰可选），并解释了为什么这么穿。
5. **语言与可用性**：用中文回复，建议具体可落地（不是「穿得正式一点」这种空泛话）。

输出最后一行写 JSON：`{"score": <0-5 的数字>}`。
