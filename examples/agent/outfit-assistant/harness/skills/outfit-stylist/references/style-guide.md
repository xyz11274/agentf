# 穿搭参考手册

推荐时据此给出**有理由**的搭配。这是工具，不是教条——用户明确的偏好优先于通则。

## 1. 配色

- **配色逻辑**（任选其一为主）：
  - 同类色：同色系深浅叠加（如 米白＋燕麦＋驼），高级、稳，最安全。
  - 邻近色：色轮相邻（蓝＋绿、橙＋黄），自然和谐。
  - 互补/撞色：色轮相对（蓝＋橘、红＋绿），出彩但只用一处做点缀。
  - 中性打底＋一抹亮：黑/白/灰/米/驼/藏蓝为大面积，亮色只在配饰或单品点睛。
- **一身不超过 3 个主色**（含中性色）；印花/格纹本身算一个「色块」，其余取其中一色呼应。
- **肤色冷暖**：暖调肤色配大地色/暖色（驼、橄榄、暖红、奶油）更显气色；冷调配冷色（藏蓝、灰蓝、酒红、正白、宝石色）。不确定就用中性色最稳。

## 2. 体型扬长避短（中性、尊重，不评判）

| 轮廓 | 思路 |
|---|---|
| 沙漏（腰明显） | 收腰单品强调腰线，合身不臃肿 |
| 梨形（下宽） | 上装亮色/有设计吸引视线，下装深色直筒/A字，避免紧身裤＋短上衣 |
| 苹果形（中段圆） | V领/开衫纵向延伸，避免腰部堆叠，下装可修身显腿 |
| H形（偏直筒） | 制造腰线（高腰、束腰、叠穿）增加曲线层次 |
| 倒三角（肩宽） | 下装增量（阔腿、A字、亮色），上装避免夸张肩部细节 |
| 不确定 | 走合身＋纵向线条＋高腰，普适显比例 |

> 通用显高显瘦：高腰、同色系上下、纵向线条、合身（非紧绷也非过松）、露脚踝。

## 3. 各场合 dress code

| 场合 | 正式度 | 关键词 / 单品 | 避免 |
|---|---|---|---|
| 通勤 | 商务休闲 | 衬衫/针织、西装/风衣、直筒裤/半裙、乐福鞋/小白鞋、托特包 | 过露、夸张印花、运动鞋配正装 |
| 约会 | 休闲偏精致 | 柔和配色、有质感面料、一处亮点（项链/口红色呼应），舒适能久走 | 过度暴露的用力感、全身大logo |
| 运动 | 运动 | 速干/弹力面料、运动内衣、跑鞋、分层（外套防风）、可收纳 | 牛仔等不透气、硬底鞋、累赘配饰 |
| 聚会 | 休闲到微正式（看场子） | 个性单品、亮色或缎面、配饰加分；室内可大胆些 | 太居家、与场合气氛脱节 |
| 面试/正式 | 正式 | 成套西装或衬衫＋西裤/裙、低饱和、整洁、皮鞋 | 鲜艳撞色、运动鞋、过多配饰 |
| 居家/休闲 | 休闲 | 棉质、卫衣、舒适直筒、小白鞋 | 不适用过度正式 |
| 旅行 | 休闲＋机能 | 易叠穿、耐脏深色、好走的鞋、一件百搭外套 | 难打理面料、高跟 |

## 4. 温度分层（按体感温度 feels_like）

| 体感区间 | 层数/单品 |
|---|---|
| ≥ 28℃ | 单层：短袖/无袖、薄连衣裙、短裤/薄长裤、凉鞋；防晒薄外套备选 |
| 23–27℃ | 单层长袖或短袖＋薄外搭（薄衬衫/防晒衣） |
| 18–22℃ | 两层：上衣＋薄针织/衬衫或风衣 |
| 12–17℃ | 风衣/夹克＋针织，或卫衣＋外套 |
| 6–11℃ | 大衣/厚夹克＋毛衣＋打底，围巾 |
| 0–5℃ | 厚大衣/羽绒＋毛衣＋保暖打底，围巾手套 |
| < 0℃ | 重羽绒＋多层保暖，护好颈/手/脚 |

**天气修正**：有雨→防水外套/雨具、避免易湿面料与浅色易脏鞋，可换防水鞋；风大→防风外套、收住围巾/裙摆；湿度高→透气面料；昼夜温差大→可脱穿的叠穿。

## 5. 风格词典（帮用户对齐审美）

- **简约/极简**：中性色、利落剪裁、少配饰。
- **法式**：条纹、衬衫、风衣、平底鞋，松弛精致。
- **通勤/知性**：西装、衬衫、半裙、低饱和。
- **街头**：oversize、卫衣、工装、运动鞋、撞色。
- **复古**：高腰、格纹、polo/针织背心、乐福鞋、棕色系。
- **运动/机能**：速干、夹克、跑鞋、功能配色。
- **甜美/温柔**：柔色、针织、连衣裙、圆头鞋。

询问或从历史推断用户偏好后，围绕一个主风格搭配，别风格混杂。
