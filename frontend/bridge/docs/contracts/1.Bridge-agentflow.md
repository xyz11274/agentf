## 1. 传输层

### 1.1 连接方式

Bridge 通过 **单个持久 WebSocket 连接** 与 agentflowd daemon 通信：

```
ws://{daemon_host}:{daemon_port}
```

默认地址：`ws://127.0.0.1:17891`（见 `config.py` → `BridgeSettings.daemon_host/daemon_port`）

### 1.2 JSON-RPC 2.0 框架

所有请求和响应遵循 JSON-RPC 2.0 规范，在 WebSocket text frame 中传输。

**请求格式**：
```json
{"jsonrpc":"2.0","method":"agent.execute","params":{...},"id":1}
```

**成功响应**：
```json
{"jsonrpc":"2.0","result":{...},"id":1}
```

**错误响应**：
```json
{"jsonrpc":"2.0","error":{"code":-2,"message":"Agent not found"},"id":1}
```

### 1.3 推送通知

Daemon 通过同一 WebSocket 连接推送通知（无 `id` 字段的 JSON-RPC 消息）：

```json
{"jsonrpc":"2.0","method":"agent.response","params":{...}}
```

Bridge 的 `DaemonClient._handle_message` 将通知路由到 `_response_queues[dialogue_id]` 队列，供 `wait_for_response` 消费。

### 1.4 重连策略

- 自动重连：`DaemonClient.connect()` 支持最多 3 次重试，指数退避（0.5s → 1s → 2s）
- 发送请求前检测：`send_request()` 发现 WebSocket `close_code` 非 None 时主动触发重连（重试 2 次，退避 0.3s → 0.6s）
- 后台监控循环：`main.py` 的 `_daemon_status_poll_loop` 以 `daemon_status_refresh_interval`（默认 **10s**）为间隔循环检测 daemon 连接状态，未连接时自动调用 `connect()` 透明重连

#### `agent.load`

**请求参数**：
```json
{"package_path": "/opt/agentflow/packages/my-agent"}
```

#### `agent.execute`

**请求参数**：
```json
{
  "agent_id": "harness-agent",
  "user_id": "bridge-user",
  "client_id": "bridge",
  "content": "用户消息文本",
  "dialogue_id": "uuid-dialogue-id",
  "stream": true,
  "request_id": "...",
  "platform_context": {}
}
```

**响应**（返回 task_id）：
```json
{"task_id": "msg-xxx", "session_id": "sess-xxx"}
```

**用途矩阵**：

| 调用方 | stream | platform_context | request_id | 预期响应 |
|--------|--------|-----------------|------------|---------|
| `chat.py` (WebSocket) | `true` | `null` | 自动生成 | 返回后立即进入 notification 等待循环 |
| `chat_rest.py` (SSE) | `true` | `null` | 自动生成 | 同上 |
| `coremind_internal.py` | `false` | 传递 ServiceSnapshot | `original_request.RequestID` | 同步等待 `wait_for_response` |
| `aisf_tasks.py` | `false` | `null` | 自动生成 | 后台异步执行 |

#### `agent.send_control`

**请求参数**（用于对话中断）：
```json
{
  "agent_id": "harness-agent",
  "command": "DIALOGUE-INTERRUPT",
  "session_id": "sess-xxx",
  "dialogue_id": "uuid-dialogue-id"
}
```

## 3. 推送通知（Server-Sent）

### 3.1 `agent.response`

当 Agent 完成一个工作流（workflow）执行后，daemon 推送此通知。

**推送形式**（WebSocket JSON-RPC notification，无 `id` 字段）：
```json
{
  "jsonrpc": "2.0",
  "method": "agent.response",
  "params": {
    "content": "...",
    "metadata": {
      "dialogue_id": "uuid-dialogue-id",
      "final": true,
      "chunk_type": "text",
      "task_id": "msg-xxx"
    },
    "artifacts": []
  }
}
```

**消费链路**：
```
Daemon WebSocket
  → _ws_reader → _handle_message
    → 匹配 method == "agent.response"
      → 提取 params.metadata.dialogue_id
        → 放入 _response_queues[dialogue_id]
          → wait_for_response() 消费
```

**关键字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `params.content` | string | 响应文本内容（chunk 或最终） |
| `params.metadata.dialogue_id` | string | 关联的 dialogue ID |
| `params.metadata.final` | bool | 是否为该 dialogue 的最终推送 |
| `params.metadata.chunk_type` | string | 块类型：`text` / `progress` / `llm_token` / `skill_output` |
| `params.artifacts` | array | 产物列表 |

| Bridge Route | 使用的 Daemon 方法 | 用途 |
|-------------|-------------------|------|
| `routes/agents.py` | `agent.list`, `agent.info`, `agent.load`, `agent.unload`, `agent.pause`, `agent.resume` | Agent CRUD 代理 |

## 5. 错误码映射

Bridge 将 daemon 的 JSON-RPC 错误码映射为 HTTP 状态码：

| JSON-RPC 错误码 | HTTP 状态码 | 含义 | Bridge 异常类 |
|----------------|-------------|------|-------------|
| `-32602` | 400 | Invalid Params | `InvalidParamsError` |
| `-2` (404) | 404 | Not Found (Agent/Session) | `NotFoundError` |
| `-1` (422) | 500/422 | Operation Failed | `DaemonError` |
| `-3` | 500 | Workflow Not Found | `DaemonError` |
| `-32000` (timeout) | 504 | Gateway Timeout | `DaemonTimeoutError` |
| WS close / 连接失败 | 502 | Bad Gateway | `DaemonConnectionError` |
| 其余 | 500 | Internal | `DaemonError` |

## 6. 不经过 Daemon 的 Bridge 自有功能

以下功能由 Bridge 直读文件系统或自有存储实现，不调用 agentflowd 接口：

| 功能 | 实现方式 | 路由 |
|------|---------|------|
| Agent Package 文件树浏览 | 直读磁盘 `agent_packages_path` | `routes/packages.py:get_package_tree()` |
| 文件 CRUD | 直读/写磁盘 | `routes/packages.py:read_file/write_file/rename_file/delete_file` |
| Package 创建/上传/更新 | 直写磁盘 + merger.py 模板合并 | `routes/packages.py:create_package/upload_package/create_from_template/update_package` |
| Package 构建(tar.gz) | shell out to `agent_build.sh` | `routes/packages.py:build_package` |
| 持久化 Session 历史 | `SessionProvider`（local SQLite / 可配置） | `routes/sessions.py:/persistent/*` |
| Conversation 存储 | `ConversationStore`（内存 + 文件） | `routes/conversations_api.py` |
| Skill Hub 元数据 | 直读 `agent_packages_path/harness/skills/` | `routes/skill_hub.py` |
| Artifact 服务 | 直读 artifact 目录 | `routes/artifacts.py` |
| 配置注入 | 读 `config.yaml` → 写 Agent `.env` | `routes/agents.py:_inject_agent_env_defaults()` |
| CoreMind SideCar UDS Server | 独立 UDS 服务发现 | `coremind_bridge/`（C++ 侧车） |
