# 已发布seed04：四道题为什么做对、为什么做错

这里看的是业务发布版本`seed004`。电影、发票、签到是额外诊断题，不计入发布500题；充值属于发布500题。L0是没有这些经验的对照版本。下面说的训练，是从运行记录中整理经验，模型参数没有改变。

## 1. 电影推荐＋健康问答：拿到结果，还要真正交给用户

`QA_GY_WYYL_011`。L0→seed04：严格通过 **0→1**，质量 **2/3→1**，无效loop **8→2**。

**发生了什么：** 用户要电影推荐和健康问答，后面又问了两轮。L0的电影工具连续三次返回空列表，最后自己写了片名，漏掉规定的电影列表和核心看点。后两轮答对了，首轮仍然失败。seed并行派发电影和健康技能，`recommend`拿到电影列表，最后给出片名和看点，三轮都通过。

**为什么：** 工具有这项能力，L0没拿到合格结果，就用自己的答复顶上了。seed拿到了工具结果，也把用户要的内容给全了。当前归档训练有`GAP012_DELIVER_ACTUAL_RESULTS_01`，要求给出真实片名和工具提供的看点；发布经验`shared-bbd575…`提醒已有完整结果时直接使用，别再多查一遍。但它没规定本题该怎么调用工具，不能证明这张经验让本题变好了。

**怎么补：** 补练空列表后的处理：确认调用是否合适，避免重复同样的空查询；结束前检查片名、列表和看点是否真的给了用户。已有结果的使用提醒可以保留，但它管不了前面选错调用的问题。

## 2. 最近一个月话费发票：一开始就派错了技能

`CK_GUI_FHCK_00_004`。L0→seed04：严格通过 **1→0**，质量 **1→0**，无效loop **1→0**。

**发生了什么：** 本题要“打开发票页、选最近一个月、发起开票”的操作计划。L0交给`device-gui`，给出了合格计划。seed交给`service-manager`，得到业务未接入的信息，转而解释不能开票、索要抬头和税号，三个必需步骤都没给。

**为什么：** 这题需要GUI操作计划，seed却走了业务办理的路线，问了资料，却没有给计划。发布包的11条经验里，没有提醒这种发票规划该交给GUI技能。`shared-19ca…`只提醒调用`plan`时带齐`query`和`title`，技能选错之后，这条提醒帮不上忙。这里能确认发布经验缺了这一项，不能据此说整个训练集没有类似题。

**怎么补：** 加入“给操作计划”和“实际办理”的对照例子，让派发前先分清用户要哪一种；再检查是否给全三步。设备没连接也可以交付计划，L0已经做到过。少绕圈并不够，走错方向后很快结束仍然失败。

## 3. 酷狗每日签到：计划已经有了，最后却没给出来

`CK_GUI_FHCK_00_061`。L0→seed04：严格通过 **1→0**，质量 **1→0**，无效loop **10→0**。

**发生了什么：** seed选对了`device-gui`，工具也生成了计划。最终回复却只说“已生成完整的操作计划”“我现在直接回复用户”，没有列步骤。它还复述了“必须逐条列出taskPlan.steps”，但说准备做，没有真的做。

**为什么：** 不能说没有类似训练。当前`GAP012_COMPLETE_PLAN_DELIVERY_01`就要求逐项展示计划，并注明未执行；它参考评测反馈构造，来源包括本题，不能当作发布前已学过的证明。当前候选`candidate:1479f918…`也有正确示例，但尚未批准：支持记录是1条对话、2条片段，要求是2条对话、2条片段。这只能说明现在，不能说明发布时发生了什么。能确认的是，发布包11条经验没有完整交付计划的提醒。

**怎么补：** 再采集不同对话中的成功记录，满足现有批准要求；结束前检查用户答复里是否真的有计划步骤。只提醒“记得回复”不够：工具完成和用户收到是两件事，无效loop降到0也不能代替交付。

## 4. 指定88元话费充值：计划通过，不代表已经付款

`CK_GUI_FHCK_00_003`。L0和seed都严格通过，质量都是 **1**，无效loop都是 **0**。

**发生了什么：** L0先检查设备，再生成计划；seed先生成计划，再尝试`execute`。两边计划步骤逐字相同，都包含充值页面、号码、88元金额和确认提交。本题检查的是计划，所以都通过。两边设备都未连接，seed执行返回`unsupported`，没有实际扣费。

**为什么：** L0本来就能完成这份计划。seed唯一实际使用的`shared-5a15…`要求写入记忆后回读验证，与充值步骤无关。GUI结果在event-65已经返回，这条经验到event-80才应用，解释不了此前的规划，也不能把本题通过算成它带来的新收益。

**怎么补：** 规划题检查步骤是否完整；真付款需要连接设备和可用的操作能力，并确认执行结果。当前归档训练有充值30元、缺手机号和支付方式时只给计划的例子，但增加类似题不会让未连接的设备自动完成付款。

## Hermes可以借鉴什么

[Hermes技能文档](https://hermes-agent.nousresearch.com/docs/user-guide/features/skills/)把操作步骤、常见错误和完成检查放在一起。这里可借鉴的是：选对技能、做完步骤后，再检查用户是否收到结果、操作是否真执行。它是否比seed04更好，仍要用同样的题实际比较。
