# Trajectory Evolution 文档

[项目简介](../README.md) · [快速开始](04-quickstart.md) · [公共＋私有记忆](14-shared-memory.md) · [图集](figures/README.md)

本手册介绍组件的安装配置、框架接入、算法流程、数据结构与运维方法。
当前统一协议为 `evolution.boundary.v1`。L0–L3 提供采集与运行控制，L4 在后台进行 GEPA 多轮搜索和准入发布，复用相同打点。

每章按目标、设计、使用、实现和边界展开；图示是阅读辅助，字段约束以随包协议和当前源码为准。
SVG 沿用浅色分区、蓝绿紫配色和圆角卡片，直接显示于 Markdown；点击“放大 SVG”可查看文字。

公共＋私有记忆管理默认开启；公共语义提炼需要配置模型，经验注入由部署授权控制。

## 重要约定

- 原生业务边界采用有界内存路径；跨进程任务使用 HTTP 服务维护共享状态。
- 各框架和语言通过统一数据契约，在任务、模型、动作与循环位置接入。
- published 表示公共经验发布状态，applied 表示策略应用核验结果，completed 表示执行终态。
- 模型示例中的外部供应商只属于可选演示；核心不绑定用户个人 API、远程机器或私有路径。
- 所有专章与图片都在本组件的 docs 中；安装包会一并交付，不依赖 AgentFlow 根目录的 docs。
