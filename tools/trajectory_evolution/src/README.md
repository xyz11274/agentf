# 内部源码导航

此目录只放实现细节；对外稳定接口仍在 `include/`、`clients/` 和 `api/`。

源码采用中文函数说明和关键分支注释：重点记录输入约束、状态转换、失败隔离、
资源所有权、隐私边界与设计原因。协议字段名、错误码和公开符号保持兼容。
包根目录的 `.clang-format` 固定 C/C++ 等源码排版；生成文件和第三方依赖不手工修改。

| 目录 | 主要职责 |
| --- | --- |
| `analysis/` | 轨迹校验、规则/模型评测、loop 分析与批次进化流水线。 |
| `cli/` | 命令路由和参数解析，不承载进化算法。 |
| `evaluation/` | 数据集执行、真实 Agent 宿主管理、轨迹采集与统一判分。 |
| `gepa/` | 候选搜索、节点融合、控制规则生成及重试证据。 |
| `memory/` | 公共/私有经验的关系判定、晋升、冲突和淘汰。 |
| `model/` | 模型请求、输入裁剪、结构化响应契约与运行配置。 |
| `runtime/` | L1–L3 策略查询、注入、编排与 loop 控制。 |
| `service/` | 本地/HTTP 接入服务、JSON 边界和多语言本地绑定。 |

主要调用路径：`cli/main.cpp` 进入评测/进化命令；`evaluation/task_evaluation.cpp` 执行逐题评测；`evaluation/agent_evaluation.cpp` 调度候选；`gepa/gepa_search.cpp` 生成并比较搜索节点；`runtime/` 中的实现只消费已确定的策略版本。

目录分组不改变策略等级。L0 不加载进化策略；L1/L2/L3 是否实际生效，要看真实执行轨迹而不能只看规则是否存在。
